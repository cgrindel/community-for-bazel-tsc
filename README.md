# Community for Bazel TSC

This repository holds the governance records of the Community for Bazel
Technical Steering Committee (TSC).

## What is here

- [GOVERNANCE.md](GOVERNANCE.md): how the TSC adds, removes, and manages its
  members.
- [MEMBERS.md](MEMBERS.md): the current TSC roster.
- [policies/](policies/): policies the TSC has adopted, such as the
  [Bazel Slack admin policy](policies/slack-admin.md).

## How changes are made

Changes to membership and policies are made by pull request. A merged pull
request is the record of the decision.

## Meeting notes and announcements

Meeting notes and announcements are posted in
[GitHub Discussions](https://github.com/cgrindel/community-for-bazel-tsc/discussions).

## Future home

We intend to propose moving this repository to the
[bazel-contrib](https://github.com/bazel-contrib) organization.
